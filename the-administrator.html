Developer Notes

PIN: Default is 482650. To change: open browser console, run
crypto.subtle.digest('SHA-256', new TextEncoder().encode('YOUR_PIN'))
  .then(b => console.log([...new Uint8Array(b)].map(x=>x.toString(16).padStart(2,'0')).join(''))) then paste the hash into PIN_HASH in this file.

Admin Access: Set is_admin = TRUE on a profiles row in Supabase. Once set, only that account can perform privileged actions through the Edge Function — the PIN gate handles page-level access.

Login as User: In Supabase Dashboard → Authentication → Users, find the user and click Send magic link. Paste that link in an incognito window to log in as them.
